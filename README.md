# Bicicletas Elétricas **BIKCRAFT**

Landing page completa para **BIKCRAFT**, loja fictícia especializada em bicicletas elétricas premium. Desenvolvido como projeto final prático de curso intensivo de **HTML, CSS e JavaScript** para iniciantes, focando em layouts modernos com Flexbox, Grid e interatividade básica.

## **Funcionalidades Principais**
- **Página Inicial**: Hero com destaque para Nimbus Stark (R$4.999), call-to-action "Compre Agora" e specs (50km/h, 36h bateria).
- **Produtos**: Catálogo com Nimbus Stark, Nebula Cosmic e Magic Might, cards responsivos com preços e botões.
- **Páginas Completas**: Sobre, Produtos, Contato – todas com navegação fluida.
- **Design Responsivo**: Disgn 100% responsivo, adaptável desktop/tablet via media queries CSS.
- **UI Moderna**: Header fixo com menu horizontal responsivo (Bicicletas | Seguros | Contato), footer com contatos, seções grid/flexbox.

## **Tecnologias e Skills Aplicadas**

| **Skill** | **Descrição** | **Exemplo no Projeto** |
|-----------|---------------|------------------------|
| **HTML5** | Estrutura semântica (header, main, section, footer) | `index.html`, formulários de contato |
| **CSS3** | Flexbox para alinhamentos, Grid para layouts complexos | Header menu, grid de produtos |
| **JavaScript** | Menu mobile interativo, smooth scroll, active menu | `js/script.js` - toggle menu + navegação |
| **Layout Responsivo** | Viewport meta, media queries (@media screen) | Mobile: menu compacto; Desktop: horizontal "Bicicletas | Seguros | Contato" |
| **Git/GitHub** | Versionamento com commits semânticos + GitHub Pages ativo | Histórico completo + deploy live |
